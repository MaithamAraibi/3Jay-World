# Arcanum: The Shattered Meadow

A first-person wizard sandbox in a single file, `index.html`, built on Three.js r160 loaded from a CDN.
There are no model, image or audio files: geometry, textures, physics, particles and sound are all generated in code.

Open `index.html` in a modern browser and click to enter.

| Input | Action |
| --- | --- |
| WASD / Shift / Space | Move, sprint, jump |
| Drag the mouse | Look around |
| Click or F | Cast at the rune circle |
| 1–7 or mouse wheel | Switch spell |
| R | Rebuild the world |
| H | Hide the help panel |

Spells: Inferno, Void Singularity, Fire Tornado, Glacial Nova, Storm Lance, Gale Blast, Verdant Bloom.

Add `?lowspec` to the URL for less grass, a smaller shadow map and no MSAA.
